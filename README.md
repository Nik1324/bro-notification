## Bro Notification 
## Описание 
Приложение в котором вы можете создавать группы напоминаний для удобного планирования задач, предполагалось, что уведомления будут приходить на смартфон и дублироваться на умных часах, вы можете выбрать два типа уведомлений - одиночное и периодичное, в каждом из них вам нужно выбрать в какие дни недели вы хотите получать уведомления, далее в одиночном - выбрать время уведомления, в периодичном - выбрать временной промежуток, например с 12:00 до 17:20, и частоту, например каждые 20 минут. Группы нужны чтобы объединять напоминания одной тематики и при необходимости отключать уведомлений у всех уведомлений этой группы
